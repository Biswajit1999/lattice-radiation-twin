# HST replicated-cohort protocol

This protocol was frozen after inspecting the initial eight-epoch development result and before querying products or reading pixels for the replication cohort. It therefore validates repeatability and operating-condition sensitivity, not an untouched claim formulated before all development data. The 2025 temporal holdout is not to be extracted until HST nuisance handling and the baseline comparison are frozen.

For each July archive-query snapshot, retain only individual ACS/WFC observations whose identifier ends in `q`. Sort by start MJD and identifier. On each distinct integer-MJD day, choose the first two observations that start in chronological order, differ by no more than one day, and have exposure durations agreeing within 1%. Keep the first three distinct-day pairs. Require public RAW and matched SPT products; absence is an error, not permission to substitute a different product.

The first selected pair in each of 2003, 2006, 2009, 2012, 2015, 2018, 2021 and 2024 is the already examined development pair. Pairs two and three are within-epoch replication data. The intended July 2025 holdout must also supply three distinct-day pairs. If it does not, query subsequent calendar months in chronological order through August 2026, preserve every attempted query, and use the first month satisfying the same three-pair rule. This fallback was recorded after July 2025 metadata showed only one eligible date, without reading any new pixel product or scientific outcome. Selection uses archive metadata only: no trail, hot-pixel, background, temperature or outcome value may affect membership.

Replication analysis will use the already frozen ACSCCD/CRDS calibration and extraction rules. Report each pair separately before any epoch pooling. Compare sign, signal dependence, transfer dependence, background, post-flash status, temperature channels and control statistics. Do not delete discordant pairs. The primary longitudinal claim requires consistent direction across replicated pairs and acceptable blank controls after a declared multiplicity treatment. A mixed-effects or measurement-error model must retain pair variation; the column bootstrap alone is insufficient.

The 2025 holdout may be downloaded and checksum-pinned, but pixel arrays and derived outcomes must remain unopened until preprocessing, nuisance covariates, baseline models, model-selection metrics and failure thresholds are versioned and pushed. Archive product metadata, file sizes and checksums are not scientific outcomes. If the holdout is accidentally read early, record the breach and select a later untouched time block rather than relabelling it.
